# Mangayomi iOS Installation

1) ارفع مجلد `extension/` على خادمك وضع رابط `index.json`.
2) افتح Mangayomi على iOS.
3) من تبويب Extensions اضغط على علامة + ثم Add Repository.
4) الصق رابط `index.json` واضغط Add.
5) افتح الريبو الجديد، ثم اضغط Install على الإضافة.
6) بعد التثبيت، ادخل إلى تبويب Novels واختر المصدر الجديد.

ملاحظة: عدّل `baseUrl` و `source` داخل `index.json` وروابط `SOURCE_BASE_URL` و `BROWSE_PATH` داخل `source.js` قبل النشر.
